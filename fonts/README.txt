Drop Evolventa here to get the exact Figma typeface (OFL licence):
  Evolventa-Regular.woff2 (or .ttf)
  Evolventa-Bold.woff2    (or .ttf)
If the files are absent, the page uses a local Evolventa / URW Gothic / Century Gothic
and finally Jost from Google Fonts. Line widths are locked to the Figma metrics
(SVG textLength), so the composition stays identical either way.
